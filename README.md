<h5 align="left">About Me</h5>

I'm Melody Kelly, a junior security engineer and analyst based in Malawi, with nearly two years of experience across Python, React.js, Bash, Wireshark, and SIEM tools. I've worked on many projects, often self-taught and usually from start to finish: setting standards, reviewing PRs, planning roadmaps, and shipping maintainable system scripts.

While continuing to build my monitoring skills, I keep contributing to open-source work that helps me improve my monitoring and investigation abilities. One example is <strong>SOC Web Recon Scanner</strong>, a website security scanner with a core engine (Nmap) and a maintainable framework. The stack is Python (FastAPI, Uvicorn, python-nmap, Requests) with an Express and HTML5 interface. I'm also planning a Java engine to improve detection coverage and the accuracy of the information it returns. I'm the sole maintainer across the stack.

Alongside other projects, my main focus right now is <strong>Web Recon</strong>. It's built on strong Python and security tools, with about 85% accuracy so far. It's still being improved, but it already does more than I imagined.

When I'm not working on those, you'll find me writing GitHub Actions, hunting for vulnerabilities on my OS, following cybersecurity updates, filing applications, and contributing to whatever open-source project I happen to be using.
